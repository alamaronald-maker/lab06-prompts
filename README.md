## Descripción

Este repositorio contiene las actividades desarrolladas en el Laboratorio 06, donde se experimenta con técnicas de ingeniería de prompts, tokens, ventana de contexto, temperatura y estructuración de instrucciones mediante ChatGPT.

## Contenido del proyecto

- `prompts/BITACORA.md`: bitácora con el desarrollo de los ejercicios, resultados, análisis y reflexiones.
- `simulador/`: archivos del simulador de temperatura desarrollado en Java.

## Ejercicios desarrollados

1. Influencia de las instrucciones.
2. Tokens y ventana de contexto.
3. Temperatura y variabilidad de respuestas.
4. Prompt vago frente a prompt estructurado.
5. Anatomía de un prompt.
